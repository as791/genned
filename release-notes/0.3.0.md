- **Content Credentials (C2PA) are now checked** (Android 9 and newer). Some generators, editors and cameras sign a record into the file of how it was made. Genned verifies that signature on the phone, against the official C2PA and Content Authenticity trust lists bundled with the app. If a trusted signer says the file was made with generative AI, that is the answer. If a trusted signer says it was captured with a camera and no AI was declared, the answer is "likely real". Credentials from unknown signers, or that fail verification because the file was changed after signing, are shown but never counted. Most apps and social networks remove these records, so you'll usually see "none found": share or save the original file to keep them. Videos are checked too.
- **Still fully offline.** Nothing is downloaded to check credentials. Files that only link to credentials stored online are reported as not checked. The app still has no internet permission, and CI now fails any build that gains one.
- **Smaller downloads.** Each release now also has one APK per processor type. Most phones want `arm64-v8a` (about 158 MB); the universal APK (about 230 MB) still works everywhere. Content Credentials checking accounts for about 19 MB of the arm64 APK. It isn't included for x86 devices (emulators, some Chromebooks), where the check shows as not available.
- **Ready for translation.** All result text now comes from string resources (English only for now), and history dates follow your phone's date format.
